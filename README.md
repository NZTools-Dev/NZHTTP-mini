# 🌐 NZHTTP-mini

가볍고 빠르게 실행할 수 있는 윈도우용 미니 HTTP 서버(Portable Web Server) 프로그램입니다. 로컬 환경에서 웹 테스트나 파일 공유가 필요할 때 간편하게 사용할 수 있습니다.

## ✨ 주요 기능
- 가볍고 빠른 경량 HTTP 서버
- 설치가 필요 없는 포터블(Portable) 지원으로 어디서나 실행 가능
- 직관적인 인터페이스와 간편한 디렉토리 공유

## 📥 다운로드
이 저장소의 **Releases** 메뉴 또는 파일 목록에서 최신 버전의 압축 파일을 다운로드하실 수 있습니다.
- **Portable 버전 (`_x64.zip` / `_x86.zip`):** 압축 해제 후 곧바로 실행할 수 있습니다.

## 🚀 사용 방법
1. 프로그램을 실행합니다.
2. 서비스할 루트 폴더 경로와 포트 번호를 지정합니다.
3. 서버를 시작(Start)하여 로컬 혹은 네트워크에서 접속을 확인합니다.
